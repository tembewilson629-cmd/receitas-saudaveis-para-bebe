# Landing Page Launch

Execute a landing page conforme o documento anexado. Implemente a estrutura exatamente como definida, utilizando os ficheiros anexados, mantendo o design mobile-first, carregamento rápido e foco em conversão. Não adicione elementos, secções ou funcionalidades que não estejam especificadas no documento.  Imagens do carrossel presentes nos anexos, o último anexo é a capa que vai aparecer na oferta
